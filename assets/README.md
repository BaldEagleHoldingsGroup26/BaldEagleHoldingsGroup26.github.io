# assets

Put these two files here:

- `photo.jpg`  — square crop, ~600x600, under 500 KB. **Worth 3 rubric points.**
                 If this file is missing the page falls back to your initials
                 and you lose those 3 points silently.
- `resume.pdf` — optional, but it satisfies the "career item" requirement for free.

Do NOT put video files here. See .gitignore.
